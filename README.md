ToScann и Consentify по зрелости находятся примерно там, где вы будете к 17:30 — это не конкуренты, это соседи по хакатону. Сравнивать себя на защите надо с Fine Print, остальных упомянуть одной строкой.
Где вы выигрываете
1. Архив — архитектурно закрытая для Fine Print фича. Они публично обещают не хранить текст соглашений и удалять его после анализа. Нельзя показать diff того, что ты не сохранил. Это не пробел в их функционале, который закроют патчем, — это следствие их обещания приватности. Плюс мониторинг изменений они держат за платным планом. Ваш бесплатный открытый архив с версиями бьёт сюда напрямую, и этот аргумент на защите звучит сильно: «конкурент не может это сделать, не отказавшись от своего же обещания».
2. Главное — и я бы вокруг этого строил весь проект. Все трое читают только документ. Никто не смотрит, что сайт делает на самом деле. Расширение в браузере — единственная точка, где видно и то, и другое одновременно.
Поэтому не «зачем сайту эти разрешения», а противоречие между обещанием и поведением: политика говорит «мы не передаём данные третьим лицам» — а страница ставит 14 сторонних трекеров, вот их список. Политика не упоминает геолокацию — а сайт её запрашивает. Это уже не сводка юридического текста, это проверка документа фактами, и формулируется одной фразой со сцены: «сайт обещал одно, а делает другое — вот доказательство».
Заодно это аккуратно ложится на тему «Интернет больше не доказательство», если решите заявляться по ней, а не по Open Source × AI.
3. Утечки — привязывайте к сайту, а не к пользователю. Обоснование ниже, оно техническое.
4. Отсутствие лимита. У Fine Print бесплатно 2 анализа в месяц. Открытый проект на своём ключе DeepSeek — без лимита. Это понятная цифра для слайда.
Реализуемость за 4:19 — честно
Три фичи в заявленном виде вы не успеете. Но одна из них дешевле, чем вы думаете, а одна дороже — и ровно наоборот тому, что вы ожидаете.
Утечки: переверните фичу. Поиск по email в Have I Been Pwned требует платного ключа, и документация прямо запрещает дёргать такие эндпоинты из клиента — ключ утечёт к пользователям, значит нужен ваш бэкенд-прокси. Это минус час и привязанная карта. Бесплатно и без ключа доступны два других:
api.pwnedpasswords.com/range/{первые 5 символов SHA-1} — без ключа, без рейт-лимита, CORS для всех источников. Проверка пароля по k-анонимности, сам пароль никуда не уходит. Прямо из расширения, ~20 минут.
/api/v3/breaches?Domain=... — список известных утечек по домену, без авторизации и с CORS.
Второй эндпоинт даёт вам то, чего нет ни у одного конкурента: открываешь сайт — видишь, сколько раз этот сайт терял данные пользователей и когда. Это сильнее, чем «проверь свою почту», потому что оценивается сайт перед тобой, а не абстрактный пользователь. И бэкенд не нужен вообще.
Архив: не ждите изменений, возьмите их из прошлого. Главная проблема трекера изменений — в день демо у него нет истории, diff показывать нечего. Решается Wayback Machine: archive.org/wayback/available?url=... и CDX API работают без ключа, я проверил — для vk.com/privacy снимок отдаётся. Вытаскиваете две архивные версии соглашения любого крупного российского сервиса, дифаете, прогоняете через модель «что изменилось для пользователя» — и у вас готовый реальный diff вместо пустой таблицы. Это превращает самую дорогую фичу в самую выигрышную по соотношению эффекта к часам.
Что режем без обсуждения: регистрацию и аккаунты, свой бэкенд и базу (всё в chrome.storage.local), поиск утечек по email, мониторинг в фоне по расписанию, «подписание» сайтов как отдельную сущность с юридическим смыслом.
