# Автопоиск соглашения

Откройте HTTPS-сайт и нажмите значок AmIFooled. Расширение найдёт ссылки на соглашение,
privacy policy или cookies (RU/EN), загрузит документ и покажет источник и preview.
Анализ начнётся только после «Отправить и сверить». Если документ не найден, укажите
его ссылку и нажмите «Загрузить по ссылке». Копировать полный текст не требуется.
При ошибке введённый URL остаётся для повторной попытки. Смена документа очищает
старый анализ, сохраняя независимую карточку утечек.

Автоматически пробуются до двух документов того же origin. Другой origin загружается
только по явному действию; Chrome запросит один конкретный HTTPS origin. Optional
wildcard в manifest сам по себе не даёт доступа ко всем сайтам. Разрешение сохраняется
Chrome и отзывается в настройках расширения. Отказ не запускает загрузку.

GET выполняется в расширении без cookies/credentials/referrer, кэша и редиректов.
Backend не принимает URL и не становится SSRF proxy. HTML разбирается parse5 без
запуска scripts/images/iframe. Формы, навигация и явно скрытые поддеревья исключаются.
Email, части URL и управляющие символы очищаются перед preview. В анализ идут hostname
исходной вкладки, подтверждённый текст и ограниченные наблюдения; URL документа не идёт.
Навигация/смена вкладки/закрытие popup отменяют загрузку, documentId проверяется до/после.

Лимиты: до 1000 ссылок, 30 подходящих, 6 кандидатов; до 6 секунд и 1 MiB на документ,
18 секунд на workflow; текст до 20 000 символов. Обрезка явно указана в карточке.
Только публичные HTTPS URL стандартного порта без credentials/IP/localhost/внутренних имён.
DNS не резолвится расширением: действуют сетевые ограничения Chrome.
PDF, вход в аккаунт, антибот-защита и JS-only контент могут не читаться. Для редиректа
укажите конечный URL, для PDF — HTML-версию, если есть. Отсутствие читаемого документа
остаётся честным состоянием недоступности, не оценкой безопасности.

Поиск эвристический: проверяется один документ, не весь юридический пакет сайта.
Внешние CSS не вычисляются, возможны служебные блоки — проверьте источник и preview.

Проверки: npm test, npm run test:popup, lint/typecheck/build. Тесты покрывают URL/ranking,
permissions/denial, HTML и hidden/form, размеры/deadline, отмену/documentId, no-auto-analyze,
fallback/retry, сохранение ввода и поздние ответы. Ручной smoke: Adobe.com → popup →
источник/preview → другая ссылка → ошибка/повтор; Tab/Enter и ширина 320px.
